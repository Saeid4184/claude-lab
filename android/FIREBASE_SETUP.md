# راه‌اندازی Firebase برای اپ ماشین‌آلات (یک‌بار)

این اپ عمداً به یک **پروژهٔ Firebase جدید و جدا** از اپ حراست وصل می‌شود. این مراحل را فقط یک‌بار
انجام دهید.

## مرحله ۱: ساخت پروژه
1. به [console.firebase.google.com](https://console.firebase.google.com) بروید → **Add project**.
2. یک نام بدهید (مثلاً `sobhan-fleet`)؛ Google Analytics لازم نیست.

## مرحله ۲: افزودن اپ اندروید و گرفتن `google-services.json`
1. در صفحهٔ پروژه، آیکون اندروید را بزنید (**Add app → Android**).
2. در فیلد **Android package name** دقیقاً بنویسید: `ir.sobhanbeton.fleet`
3. **Register app** → فایل `google-services.json` را دانلود کنید.
4. فایل را در پوشهٔ `android/app/` قرار دهید (کنار `build.gradle`).
   - ⚠️ مخزن گیت‌هاب شما **عمومی (public)** است. این فایل به‌طور پیش‌فرض در `.gitignore` است و
     کامیت نمی‌شود. برای ساخت APK در گیت‌هاب، به‌جای کامیت کردن، محتوای فایل را در
     **Settings → Secrets and variables → Actions → New repository secret** با نام
     `GOOGLE_SERVICES_JSON` ذخیره کنید؛ workflow ساخت خودش آن را برمی‌دارد.

## مرحله ۳: فعال‌سازی ورود با ایمیل/رمز
**Build → Authentication → Get started → Email/Password → Enable → Save**

## مرحله ۴: فعال‌سازی Firestore
**Build → Firestore Database → Create database** → حالت **Production** → یک منطقهٔ نزدیک
(مثلاً `eur3`) → **Enable**.

## مرحله ۵: قوانین امنیتی (رد نکنید)
1. در Firestore تب **Rules** را باز کنید.
2. محتوای فایل `android/firestore.rules` را جایگزین متن موجود کنید و **Publish** بزنید.

خلاصهٔ قوانین:
- **اولین حسابی که ساخته شود** = «کارشناس ماشین‌آلات» (شما) — تنها نقشی که ثبت/ویرایش می‌کند.
- **هر حساب بعدی** = «در انتظار تأیید» و به هیچ داده‌ای دسترسی ندارد، تا وقتی شما از
  **تنظیمات → کاربران و دسترسی‌ها** آن را «مدیر» کنید.
- «مدیر» همه‌چیز را می‌بیند و گزارش می‌گیرد، اما نمی‌تواند چیزی را تغییر دهد.
- این محدودیت‌ها روی سرور اعمال می‌شوند، نه فقط در ظاهر اپ.

## مرحله ۶: ساخت حساب‌ها
1. APK را نصب کنید → **«حساب ندارید؟ ثبت‌نام کنید»** → حساب **خودتان** را اول بسازید.
2. مدیرتان روی گوشی خودش ثبت‌نام می‌کند؛ پیام «در انتظار تأیید» می‌بیند.
3. شما: **⋮ → تنظیمات → مدیریت کاربران** → نام او → **مدیر**. حالا او دوباره وارد می‌شود.

## نکات
- **بدون اینترنت**: ثبت‌ها روی گوشی می‌مانند و با وصل شدن، خودکار روی سرور می‌روند.
- **هزینه**: در حجم ناوگان یک کارخانه، کاملاً داخل سقف رایگان (Spark) می‌ماند.
