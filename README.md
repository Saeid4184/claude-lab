# ماشین‌آلات سبحان بتن

اپلیکیشن اندروید مدیریت **ماشین‌آلات و رانندگان** کارخانه بتن سبحان — بازطراحی‌شده از روی اپ
«حراست سبحان بتن» (همان ساختار Kotlin + Room + Firebase، همان ظاهر و تقویم شمسی و خروجی اکسل)،
اما به‌صورت یک اپ و پروژهٔ Firebase کاملاً جدا.

- کد اپ: پوشهٔ [`android/`](android)
- راه‌اندازی Firebase: [`android/FIREBASE_SETUP.md`](android/FIREBASE_SETUP.md)

## نقش‌ها
| نقش | دسترسی |
|---|---|
| کارشناس ماشین‌آلات (اولین حساب) | ثبت و ویرایش همه‌چیز، تأیید حساب‌ها |
| مدیر | مشاهدهٔ همه‌چیز و گزارش‌گیری، بدون ویرایش |
| در انتظار تأیید (حساب‌های تازه) | هیچ دسترسی‌ای تا تأیید کارشناس |

## ساخت APK
- **با گیت‌هاب (بدون کامپیوتر)**: هر push به پوشهٔ `android/` ساخت را در تب **Actions** شروع
  می‌کند؛ فایل APK در بخش **Artifacts** همان اجرا (`sobhan-fleet-debug-apk`) است. اجرای دستی:
  Actions → **Build Android APK** → **Run workflow**.
- **با Android Studio**: پوشهٔ `android/` را باز کنید → Run.
- **خط فرمان**: `cd android && ./gradlew assembleDebug`
